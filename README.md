# Линейная регрессия с нуля: Сравнение классического подхода, псевдо-обратной матрицы и scikit-learn 📐

*Учебный проект в рамках программы профессиональной переподготовки «Аналитик данных» (НИУ ВШЭ), 2025–2026.*

## 📌 О проекте

Данный проект выполнен в рамках домашнего задания по курсу «Математика для анализа данных» программы переподготовки НИУ ВШЭ. Задача — реализовать линейную регрессию «с нуля» через матричные операции, проверить наличие линейной взаимосвязи через ранг матрицы и сравнить три подхода к нахождению коэффициентов модели.

## 📌 Цель проекта

Отработать математическую суть метода наименьших квадратов (МНК) и убедиться, что классическое матричное решение, решение через псевдо-обратную матрицу и готовая реализация из `scikit-learn` дают идентичный результат при отсутствии мультиколлинеарности.

## 📁 Данные

- **Источник:** учебный датасет `Advertising.csv`, НИУ ВШЭ
- **Размер:** 200 строк, 5 столбцов (после удаления служебного `Unnamed: 0` — 4 признака)
- **Основные поля:**
  - `TV` — объём расходов на телевизионную рекламу (в тысячах долларов)
  - `Radio` — объём расходов на радиорекламу (в тысячах долларов)
  - `Newspaper` — объём расходов на газетную рекламу (в тысячах долларов)
  - `Sales` — объём продаж после рекламной кампании (целевая переменная)

## 🎯 Основные выводы

1. **Линейной взаимосвязи между признаками нет:** ранг матрицы признаков равен числу столбцов (ранг = 4 для матрицы 200×4), определитель `XᵀX` отличен от нуля, матрица обратима. Мультиколлинеарность отсутствует.

2. **Все три подхода дают идентичный результат:**
   - Классический МНК через `np.linalg.inv(XᵀX)`
   - Через псевдо-обратную матрицу `np.linalg.pinv(XᵀX)`
   - Через `LinearRegression` из `scikit-learn`

3. **Качество модели одинаково высокое во всех случаях:**
   - **RMSE = 1.6686**
   - **R² = 0.8972** — модель объясняет ~89.7% дисперсии целевой переменной

4. **Интерпретация коэффициентов:**
   - Свободный член ≈ 2.94
   - `TV` ≈ 0.0458 — каждый дополнительный доллар на ТВ-рекламу даёт ~0.046 прироста продаж
   - `Radio` ≈ 0.1885 — самый сильный эффект на единицу затрат
   - `Newspaper` ≈ −0.001 — практически не влияет на продажи (коэффициент близок к нулю)

## 🔧 Инструменты и стек

- **Язык:** Python 3.13
- **Анализ данных:** pandas, numpy
- **Машинное обучение:** scikit-learn (`LinearRegression`, `mean_squared_error`, `r2_score`)
- **Среда:** Jupyter Notebook

## 📊 Что сделано в проекте

1. **Загрузка и первичная очистка данных:** проверка пропусков (`isnull().sum()`), удаление служебного столбца `Unnamed: 0`.
2. **Проверка линейной взаимосвязи через ранг матрицы:**
   - `np.linalg.matrix_rank(df)` = 4 при 200 наблюдениях и 4 признаках → линейной зависимости нет
   - Проверка определителя `det(XᵀX)` ≠ 0 → матрица обратима
3. **Корреляционный анализ:** построена матрица корреляций, выявлены сильные связи `Sales` с `TV` (0.78) и `Radio` (0.58).
4. **Классический МНК-подход:**
   - Добавлен столбец единиц для свободного члена
   - Вычислены коэффициенты через `w = (XᵀX)⁻¹Xᵀy`
   - Получены предсказания и метрики качества
5. **Подход через псевдо-обратную матрицу:**
   - `w = pinv(XᵀX)Xᵀy`
   - Проверено совпадение результатов с классическим подходом
6. **Подход через scikit-learn:**
   - Обучена `LinearRegression` на тех же данных
   - Проверено совпадение метрик с двумя предыдущими подходами
7. **Сравнение и интерпретация** результатов трёх подходов.

## 🧠 Проверенные гипотезы и наблюдения

- **Гипотеза о мультиколлинеарности не подтвердилась:** признаки линейно независимы (ранг = числу столбцов).
- **Классический МНК и псевдо-обратная матрица эквивалентны** при отсутствии вырожденности `XᵀX`.
- **scikit-learn воспроизводит математически точное решение МНК** — расхождений с «ручной» реализацией нет.
- **`Newspaper` — слабый предиктор:** его коэффициент практически нулевой, что согласуется с низкой корреляцией с `Sales` (0.23).
